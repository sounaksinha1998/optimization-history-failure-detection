# Optimization History Failure Detection

Associative learning-trajectory memory (optional FFT + attention) replacing nested-EMA memory in the NRO clinical failure-detection pipeline.

## Validation notebooks (canonical entry points)

Run **only the `_correctness` notebooks**. Those are the valid experiments (correctness-target associative memory). Do not use the residual-memory notebooks (`dermamnist_full_validation.ipynb`, `memory_vector_vs_magnitude_probe.ipynb`, `bloodmnist_organcmnist_probe.ipynb`) to reproduce reported results.

| Notebook | Purpose |
|----------|---------|
| [notebooks/dermamnist_correctness_memory_full.ipynb](notebooks/dermamnist_correctness_memory_full.ipynb) | DermaMNIST train + deploy + probe: \(z_{\mathrm{combined}}\) vs \(H\), \(h_T\), and cumulative level ablation |
| [notebooks/memory_vector_vs_magnitude_correctness_probe.ipynb](notebooks/memory_vector_vs_magnitude_correctness_probe.ipynb) | DermaMNIST probe only (uses the artifacts above): full vectors vs magnitudes, then \(z_{\mathrm{combined}}\) vs \(H\) |
| [notebooks/bloodmnist_correctness_organcmnist_probe.ipynb](notebooks/bloodmnist_correctness_organcmnist_probe.ipynb) | Cross-dataset \(z_{\mathrm{combined}}\) vs \(H\) on BloodMNIST and OrganCMNIST |

Run Derma training (`dermamnist_correctness_memory_full`) before the magnitude probe notebook. Retired notebooks, if present, live under `notebooks/_archived/` for reference only.

## Publication figures

After DermaMNIST Part II has written `research/correctness_memory_fft/probe_experiments/correctness_feature_cache/`, generate the paper plots (`entropy_vs_z_combined`, probe bars, ROC/PR, risk–coverage, confident-wrong) with the `_correctness` suffix:

```bash
python publication/generate_figures.py
```

Outputs go to `publication/images/*_correctness.pdf`. Architecture diagrams in that folder are static PNGs and are not regenerated by this script.
